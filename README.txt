Легкое, полностью адаптивное прогрессивное веб-приложение (PWA) с набором необходимых повседневных утилит. Этот проект, полностью созданный с использованием стандартных HTML, CSS и JavaScript, разработан с учетом скорости, простоты и возможности использования в автономном режиме без лишних внешних фреймворков.

Универсальный набор из 12 инструментов:
Генератор паролей
Генератор QR-кодов
Конвертеры базовых единиц измерения
Исправитель бессмысленных символов
Счетчик слов
Инструмент Unix Epoch
Курсы валют/криптовалют в реальном времени
Секундомер
Таймер и мировые часы.
